   - `customer_packages(customer_id, tenant_id) REFERENCES customers(id, tenant_id)`
   - `customer_packages(package_definition_id, tenant_id) REFERENCES service_package_definitions(id, tenant_id)`
   - `customer_package_redemption_ledger(customer_package_id, tenant_id) REFERENCES customer_packages(id, tenant_id)`
   - `customer_package_redemption_ledger(appointment_id, tenant_id) REFERENCES appointments(id, tenant_id)`
   - `customer_package_redemption_ledger(service_id, tenant_id) REFERENCES services(id, tenant_id)`
   - `customer_memberships(customer_id, tenant_id) REFERENCES customers(id, tenant_id)`
   - `customer_memberships(membership_plan_id, tenant_id) REFERENCES membership_plans(id, tenant_id)`

   - `admin_grant_customer_package` verifies `customer.tenant_id = p_tenant_id` before package instance creation.
3. **Appointment Validation on Redemption**:
   - `redeem_customer_package_credits` verifies appointment tenant, customer, and service match before deducting credits.
4. **Database-Enforced Append-Only Ledger**:
   - Added trigger `trg_prevent_redemption_ledger_mutation` raising exception on any `UPDATE` or `DELETE` on `customer_package_redemption_ledger`.
5. **Membership Resubscribe Semantics**:
